# ML-from-scratch
ML from scratch is a learning-focused repository where fundamental machine learning algorithms are implemented from scratch. The goal is to explore the mathematical foundations behind ML models and build them using simple code for deeper understanding.\

## Project Status

### Current Focus

The core framework is complete and functional. At the moment, the focus is on refining existing implementations before expanding the library further.

**Currently working on:**

* L2 regularization support.
* Newton's method based optimization.
* Locally Weighted Linear Regression (LWLR).
* General code cleanup and API improvements.
* Additional benchmarking and testing.

---

## Completed Milestones

### Core Framework

* Designed a modular, OOP-based machine learning framework.
* Implemented a `fit()` / `predict()` style API for models.
* Built reusable training and utility components for future expansion.

### Mathematical Foundation

* Implemented custom vector and matrix operations from scratch.
* Built supporting mathematical utilities required for ML algorithms.

### Optimization

* Implemented gradient-based optimization methods.
* Added learning rate scheduling strategies for dynamic alpha updates.

### Machine Learning Models

* Linear Regression.
* Logistic Regression.
* Closed-form solutions where applicable.

### Data Processing

* Custom CSV reader.
* Feature preprocessing utilities.
* Missing value handling.
* Stochastic probabilistic imputation for categorical data.
* Additional data cleaning helpers.

### Model Evaluation

* Implemented performance metrics for model evaluation.
* Benchmarked implementations against scikit-learn.

### Phase One Complete

Successfully built an end-to-end machine learning pipeline capable of producing results comparable to equivalent scikit-learn implementations while remaining educational and highly extensible.

## About the Author

I'm currently an undergraduate student exploring machine learning and software engineering through hands-on projects. This repository is my attempt to understand ML from first principles rather than treating existing libraries as black boxes.

The goal of this project is educational: to build, experiment, make mistakes, and learn how machine learning systems work under the hood.

I'm continuously improving both the code and my understanding, so constructive feedback, suggestions, and discussions are always appreciated.
